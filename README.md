# Кредитный скоринг

Портфолио-проект по оценке риска дефолта на данных
[Home Credit — Credit Risk Model Stability](https://www.kaggle.com/competitions/home-credit-credit-risk-model-stability/data).
Проект включает разведочный анализ, построение признаков из истории,
временную валидацию и интерактивное демо в Streamlit.

**Итоговая модель — CatBoost на 120 полях.** На поздней выборке она получила
**0,6018 Gini Stability** и нашла **45,04% дефолтов**, пометив около 10% заявок.
Это локальный результат на ранее использованных неделях 73–91.

## Ключевые эксперименты

| Модель и набор | Период оценки | Gini Stability ↑ | Средняя недельная Gini ↑ |
|---|---|---:|---:|
| LogReg, 13 полей | Поздний | 0,2951 | 0,3140 |
| CatBoost, 13 полей | Поздний | 0,4342 | 0,4562 |
| CatBoost, 27 полей | Среднее по трём фолдам | 0,4497 | 0,4730 |
| CatBoost, все 167 полей статики + история заявок | Среднее по трём фолдам | 0,5281 | 0,5536 |
| CatBoost, 120 полей | Среднее по трём фолдам | 0,5059 | 0,5618 |
| CatBoost, 120 полей + стаж | Среднее по трём фолдам | 0,5224 | 0,5709 |
| **CatBoost, 120 полей** | **Поздний** | **0,6018** | **0,6229** |
| CatBoost, 120 полей + стаж | Поздний | 0,5880 | 0,6082 |

Три фолда оценивают недели 24–33, 34–43 и 44–54. Поздний период
оценивает недели 73–91. Сравнивать варианты следует внутри одного протокола.

## Чему научил проект

- **Качество и доступность данных.** Широкая статика улучшила метрики на фолдах, но часть полей описывает параметры выдачи или агрегаты с неизвестной датой снимка. В итоговом наборе оставили более консервативную статику и добавили историю заявок и бюро. Доступность оставшихся полей в реальной системе требует подтверждения.
- **Ранжирование и стабильность.** История платежей улучшила среднюю недельную Gini, но снизила Gini Stability. Последняя дополнительно штрафует падение качества и разброс во времени.
- **Перенос на новые недели.** Стаж улучшил результат на ранних фолдах, но на позднем периоде покрытие упало с 40,65% до 22,96%. При том же объёме проверки модель со стажем нашла на 27 дефолтов меньше.
- **Калибровка при сдвиге.** Калибратор, обученный на периоде с большей долей дефолтов, ухудшил log loss и Brier на поздней выборке.

## Запуск локально

Нужны [uv](https://docs.astral.sh/uv/) и Python 3.13. Выполняйте команды из корня проекта.
Если `artifacts/scoring.zip` уже создан, сразу переходите к запуску Streamlit.
Для подготовки артефакта войдите в Kaggle и примите правила соревнования.

```sh
uv sync --locked --group app
mkdir -p data/raw
uvx kaggle competitions download -c home-credit-credit-risk-model-stability -p data/raw
unzip -n data/raw/home-credit-credit-risk-model-stability.zip 'parquet_files/train/train_base.parquet' 'parquet_files/train/train_static_0_*.parquet' -d data/raw
uv run --locked --group app train-baselines
```

Запустите приложение и откройте адрес, который напечатает Streamlit
(обычно `http://localhost:8501`).

```sh
uv run --locked --group app streamlit run app/streamlit_app.py
```

- **Оценить заявку.** Нажмите «Заполнить пример» или заполните поля вручную, затем «Оценить риск». Пустые поля считаются пропусками. На экране появится исходный скор CatBoost и отметка о демонстрационном пороге 5%.

Для страниц **«Синтетический профиль»** и **«Качество модели»** подготовьте
CatBoost на 120 полях и агрегаты его поздней проверки.

```sh
unzip -n data/raw/home-credit-credit-risk-model-stability.zip 'parquet_files/train/train_applprev_1_*.parquet' 'parquet_files/train/train_credit_bureau_a_1_*.parquet' -d data/raw
uv run --locked --group app python -m credit_scoring.late_validation --export-control
uv run --locked --group app python -m credit_scoring.review_curve
```

- **Синтетический профиль.** Выберите пример и посмотрите, какие записи истории прошли временной фильтр. Нажмите «Оценить профиль», чтобы увидеть исходный скор и восемь крупнейших вкладов SHAP. Вклады измеряются в логарифме шансов.
- **Качество модели.** Измените долю заявок на проверку. График сравнивает долю найденных дефолтов со случайным отбором на неделях 73–91.
- Для ручного ввода используется отдельный артефакт на **13 полях**.

Данные и артефакты моделей хранятся локально.
