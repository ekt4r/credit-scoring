# Скрининг оставшихся источников и производных признаков

Из десяти вариантов положительную среднюю прибавку Gini Stability дали
контракты бюро B, данные заявителя и стаж, а также признаки открытия
дебетовых карт. Наибольший прирост средней недельной Gini дал стаж.
Победитель по Gini Stability, блок контрактов бюро B, практически не
изменил среднюю недельную Gini и покрыл только 2 998 кейсов.

## Как сравнивали

Контроль — 120 полей из широкой статики после отбора, предыдущих заявок
и бюро A. Каждый блок добавлялся отдельно. Обучение шло на всех неделях
до соответствующего фолда. Для сравнения использован LightGBM 4.6.0,
100 деревьев, `max_bin=63`, одинаковые настройки для всех блоков.
Приросты считаются относительно LightGBM на 120 полях. Это скрининг
на трёх уже использованных фолдах. Перенос прироста на CatBoost и новый

## Какие признаки прошли временной фильтр

- **Бюро B.** Допустимые снимки контрактов нашлись для 2 998 из 1 129 770
  кейсов недель 0–54. У 2 314 также были данные бюро A, у 684 — только B.
  Для платежей требовалась дата строго до решения и связь с допустимым
  снимком контракта. Подошло 41 357 строк по 2 995 кейсам.
- **Заявитель и стаж.** Использованы записи `num_group1=0`, дата начала
  работы строго раньше решения. Для `person_1` подошли 459 223 кейса.
  У кандидата из `person_2` дата начала работы отсутствовала во всех
  связанных строках заявителя. Время поступления сведений о работе и
  доходе неизвестно.
- **Налоговые записи.** В A все 2 417 192 связанные строки датированы днём
  решения или позже. В B отсутствуют совпавшие кейсы в неделях 0–54.
  В C прошло 2 603 056 строк на 402 761 кейс. Дата обработки записи
  используется как приближение доступности.
- **Карты и депозиты.** Считались число открытий и давность открытия.
  Покрытие составило 74 280 и 74 287 кейсов соответственно. У остатков,
  оборотов и суммы депозита дата снимка отдельно не указана.
- **Отношения к доходу.** Текущий долг и средний исторический платёж
  делились на положительный основной доход. Это прокси на преобразованных
  суммах. Сопоставимость периодичности и единиц не подтверждена.
- **Одобрения.** Для 775 400 кейсов нашлись 2 370 091 запись с датой
  создания не позже одобрения и одобрением строго до текущего решения.
  Число и давность одобрений проверены. Доля отказов требует даты
  возникновения статуса для каждой предыдущей заявки.
- **Окна просрочек.** Число и доля записей с просрочкой за 3, 6 и 12
  завершённых календарных месяцев отдельно по активным и закрытым
  контрактам. Во втором варианте добавлены изменение доли между
  месяцами 1–3 и 4–12 и максимальная серия месяцев с просрочкой.
  Месяц без наблюдаемой просрочки прерывает серию.
- **`applprev_2` и `other_1`.** Проверено покрытие, 882 543 и 714 кейсов.
  Поля статуса карты, блокировки, оборотов и остатков требуют даты
  снимка. Приросты для этих двух источников не рассчитывались.

Для следующего подтверждения приоритет у `person_1`: блок прибавил по
обеим метрикам, хотя Gini Stability на неделях 34–43 снизилась. Текущий
набор CatBoost на 120 полях сохраняется как контроль.

## Воспроизведение

После распаковки перечисленных таблиц в `data/raw/parquet_files/train/`
выполните из корня проекта:

```sh
uv run --locked --group experiments python -m credit_scoring.feature_screen
uv run --locked --group experiments python -m credit_scoring.feature_screen --dynamics-only
```

Скрипты сохраняют агрегированные результаты в `artifacts/feature-screen/`.
Прогоны выполнены в локальном окружении. Полный прогон из lock-файла
отдельно не подтверждён.

## Перепроверка на CatBoost

Три блока с положительной средней Gini Stability на LightGBM добавлены
по одному к тем же 120 полям. Использован CatBoost 1.2.10 с 350 деревьями,
глубиной 6 и скоростью обучения 0,08, как в предыдущем прогоне контроля.
Сравнение использует те же границы недель и настройки. Контрольные
значения взяты из завершённого прогона CatBoost на 120 полях.

```sh
uv run --locked python -m credit_scoring.feature_screen --catboost
```

Результаты по фолдам сохраняются в `artifacts/feature-screen/catboost.csv`.

| Дополнительный блок | Stability 24–33 | 34–43 | 44–54 | Средняя Stability | Δ Stability | Средняя недельная Gini | Δ Gini |
|---|---:|---:|---:|---:|---:|---:|---:|
| Контроль, 120 полей | 0,4650 | 0,4973 | 0,5554 | 0,5059 | +0,0000 | 0,5618 | +0,0000 |
| Заявитель и стаж | 0,5698 | 0,4344 | 0,5631 | 0,5224 | +0,0165 | 0,5709 | +0,0090 |
| Бюро B · контракты | 0,4213 | 0,4890 | 0,5552 | 0,4885 | −0,0174 | 0,5623 | +0,0005 |
| Дебетовые карты | 0,4423 | 0,4689 | 0,5570 | 0,4894 | −0,0165 | 0,5632 | +0,0013 |

На CatBoost прирост средней Gini Stability подтвердил только блок
заявителя и стажа. Он улучшил результат на двух фолдах из трёх, а на
неделях 34–43 снизил Stability с 0,4973 до 0,4344. Числовой сигнал в
блоке пришёл из `person_1`. Поля `person_2` остались пустыми после
временного фильтра. Прогон остаётся сравнением на уже использованных
фолдах. Время поступления сведений о стаже и доходе требует подтверждения.

## Выбранный вариант

Для следующего этапа выбран **CatBoost на 120 полях с блоком заявителя и
стажа из `person_1`**. На трёх временных фолдах он набрал **0,5224 Gini
Stability** и **0,5709 средней недельной Gini**. По сравнению с CatBoost
на 120 полях прирост составил +0,0165 и +0,0090 соответственно.

| Вариант CatBoost | Средняя Gini Stability | Средняя недельная Gini |
|---|---:|---:|
| 173 поля, максимум Stability | **0,5281** | 0,5536 |
| **Выбранный вариант, 120 полей + заявитель и стаж** | **0,5224** | **0,5709** |
| 125 полей со счётчиками запросов, максимум недельной Gini | 0,4927 | **0,5750** |

Это выбор для дальнейших экспериментов на основе уже просмотренных фолдов.
Для внедрения нужно подтвердить момент поступления сведений о стаже и доходе.
